# Implementing Otsu's Method
> A Python implementation of the classic Otsu thresholding algorithm for automatic image binarization.

## Overview

This project implements **Otsu's Method**, a classic image thresholding algorithm introduced by **Nobuyuki Otsu** in 1979. The algorithm automatically determines an optimal threshold that separates the foreground from the background by minimizing the weighted within-class variance (or equivalently maximizing the between-class variance).

The primary goal of this project was to gain hands-on experience implementing an algorithm directly from the original research paper rather than relying on existing computer vision libraries such as OpenCV or scikit-image.

This implementation was developed by studying:

- **Otsu, N.** (1979). *A Threshold Selection Method from Gray-Level Histograms*. IEEE Transactions on Systems, Man, and Cybernetics, 9(1), 62–66. https://doi.org/10.1109/TSMC.1979.4310076
- Vignesh Gopalakrishnan. *Image Segmentation using Otsu Threshold Selection Method* (Medium). https://medium.com/@vignesh.g1609/image-segmentation-using-otsu-threshold-selection-method-856ccdacf22
